# iOS 1.0 (3) 장면 움직임 개선 · 2026-09-27

상태: Debug 빌드, Release Archive, 시뮬레이터 조작 검증 완료. 배포 IPA 서명 검증 완료, TestFlight 업로드 준비 중이며 실물 검증·심사 재제출은 아직이다.

## 사용자 피드백과 확인한 원인

사용자는 iPhone 16 / iOS 27 / TestFlight 1.0 (2)의 홈 및 꾸미기 장면이 끊겨 보인다고 보고했다. 기존 `CharacterComposite.swift`는 모든 `SCNView`를 24fps로 제한하고 미리보기 버튼의 카메라 전환 시간을 0초로 설정했다. 이는 코드에서 확인한 원인이며, 전체 끊김 원인을 모두 측정한 것은 아니다.

## 변경 범위

- 일반 상태의 목표 주사율을 60fps로 높인다. 저전력 모드나 nominal보다 높은 열 상태에서는 30fps로 제한한다. 기존 홈의 저전력·심한 발열·동작 줄이기 일시정지를 유지한다.
- 회전·확대·초기화 버튼에 0.24초 ease-in/ease-out 전환을 적용한다. 동작 줄이기에서는 즉시 전환한다.
- 연속 입력은 현재 표시 중인 카메라 자세에서 이어지고 이전 완료 콜백이 새로운 전환의 렌더링을 중단하지 않도록 세대 번호로 구분한다.
- 드래그가 시작되면 버튼 전환을 중단하고 직접 조작으로 넘긴다. 전환 종료·화면 이탈 시 연속 렌더링을 중단한다. 앱 비활성화·화면 밖의 미리보기도 렌더링을 정지한다.
- 디버그 전용 `--debug-room-frames`는 실제 렌더 콜백의 간격을 측정한다. `--debug-room-24fps`로 동일 코드에서 이전 목표 주사율과 비교할 수 있다. Release에는 포함되지 않는다.
- SceneKit 모델·재질·조명·행동 경로와 정적 미리보기/Watch 초상화는 변경하지 않는다. 화면 렌더링 주기 및 카메라 제어만 변경한다.
- `agvtool new-version -all 3`으로 앱·Watch·위젯의 빌드 번호를 함께 올린다.

### 관찰 결과

- iPhone 17 Pro Max / iOS 26.5 시뮬레이터 한 대만 실행했다. 기존 테스트 데이터(110P, 기본 장착 상태)를 지우지 않고 덮어 설치해 유지됨을 확인했다.
- 이전 목표 24fps: 안정 구간 120개 간격씩 3회 측정해 30.2 / 30.0 / 30.0fps, p95 33.7ms. 실제 콜백 주기는 요청값과 같지 않았다.
- 새 목표 60fps: 안정 구간에서 약 59.8~60.7fps, p95 약 17.0~17.2ms. 대표 120개 간격 표본에서는 25ms 초과 0개였다. 시작·오래 정지한 구간을 포함한 모든 프레임 지연이 없다는 뜻은 아니다.
- 카메라 회전·확대: 각각 12개 간격에서 60.0 / 59.8fps, p95 16.8 / 16.9ms. 완료 후 `continuous=false`로 복귀했다.
- 빠른 연속 회전·확대/축소 후 드래그, 원래대로(100%), 가까이/방 보기, 전환 중 닫기를 확인했다. 앱을 Home으로 내린 뒤 복귀해 115% 상태를 보존하고 다시 초기화할 수 있었다.
- `--piyak-reduce-motion`은 DEBUG에서만 시스템 환경값 대신 같은 분기에 진입한다. 홈에 ‘동작 줄이기 설정으로 쉬고 있어요’가 표시되고, 회전/확대는 작동하면서 연속 렌더링이 켜지지 않았다. 실제 OS 설정 전환의 전체 접근성 시험을 대신하지 않는다.
- Swift 회귀 테스트 115개 및 81개 미리보기/앱 아이콘/3개 개인정보 매니페스트 검사가 통과했다. 모델·생성 자산은 변경하지 않았다.
- 빌드와 시뮬레이터는 겹치지 않았다. 확인 시점의 macOS thermal/performance 경고는 없었으며 실제 온도 측정은 아니다.
- 마지막 코드 점검에서 미리보기를 숨기거나 동작 줄이기로 전환하면 카메라를 요청한 최종 위치로 정리하도록 보완했다. 연속 직접 입력은 현재 표시 자세에서 이어진다. 이 변경은 Release Archive 컴파일로 확인했으며 물리 기기 체감은 후속 TestFlight 확인 대상이다.

로컬 증거: `/Users/minseo/develop/output/piyak-smooth-20260927/`의 `cadence-24.log`, `cadence-60.log`, `inspection-final.log`, `reduce-motion.log`, `swift-tests.log`, 빌드·Archive 로그. 실행용 산출물과 서명 자료는 공개 저장소에 넣지 않는다.

시뮬레이터의 렌더 콜백 측정은 실물 기기의 실제 디스플레이 프레임·발열·배터리 측정이 아니다. 기존 전체 접근성·최소 OS·Watch 물리 연결 등 미완료 항목을 이 수정으로 완료 처리하지 않는다.

최종 배포 IPA에서 앱·Watch·위젯 모두 1.0 (3), App Store 프로파일, 디버그 권한 비활성화 및 원본 App Group 일치를 검증했다. Release 실행 파일에 프레임 측정기와 QA 오버라이드 문자열이 포함되지 않는 것도 확인했다.

## 심사 자료

자동 출시 설정을 유지한다. 기존 1.0 (2)의 회신 초안과 영상은 전송하지 않고 보류한다. 새 빌드를 실제로 확인하기 전에는 기존 영상을 1.0 (3) 촬영으로 설명하거나 새 빌드 검증 완료를 주장하지 않는다.
