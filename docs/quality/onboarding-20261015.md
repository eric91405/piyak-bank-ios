# iOS 첫 사용 가이드 · 2026-10-15

## 변경

- 신규 사용자는 앱 소개 → 근무 기록 → Apple Watch → 포인트·꾸미기의 3D 안내 4장을 순서대로 본 뒤 기본 시급을 설정한다. 스와이프·이전·다음을 지원하며 건너뛰기와 자동 넘김은 없다.
- 유효한 시급으로 마지막 시작 버튼을 눌렀을 때만 기존 `did_onboard`를 완료 처리한다. 미완료 상태로 재시작하면 안내 1장부터 다시 시작한다. 기존 사용자의 완료 값은 유지한다.
- 설정 → 이용 안내의 상단 버튼에서 같은 가이드를 전체 화면으로 다시 연다. 넓은 행의 빈 영역까지 눌러 열 수 있다. 다시 보기는 시급 입력 없이 닫기·마치기로 종료하며 기존 상세 안내를 유지한다.
- 기존 삐약이·방 모델과 안내 전용 시계·기기 모델을 사용한다. 장면은 진입 때 한 번 움직이고 5.6초 뒤 완성된 정지 장면으로 전환한다. 이전 장면을 해제하며 화면 종료 시 렌더러·작업을 해제한다.
- 동작 줄이기·저전력·심한 발열에서는 완성된 정지 장면을 표시한다. 예시 수익과 기기 화면은 실제 근무·원장·워치 제어를 호출하지 않는다.
- 접근성 글자 크기에서는 설명을 늘려 스크롤하고, 예시 카드를 그림 아래에 배치한다. 본문은 강제 줄바꿈·추가 줄 간격 없이 화면 폭에 맞춰 흐르게 한다. 상단은 진행 번호·점 표시를 중심으로 구성하고 하단 진행 버튼을 유지한다. 다시 보기에도 설정 화면의 글자 크기를 전달한다.

공용 `PiyakScene.swift`, 생성 에셋·워치 초상화, 데이터 모델·보상·동기화 정책은 변경하지 않았다. 외부 모델이나 라이브러리도 추가하지 않았다. Android·스토어 배포는 이번 작업 범위에 포함하지 않는다.
