# iOS 1.0 (5) 앱 아이콘 교체 · 2026-09-28

## 변경 범위

개발자가 제공한 `PiyakBank_AppIcon.zip`의 완성 PNG를 재가공 없이 적용했다. 기본 아이콘은 함께 제공한 1024px 이미지와 바이트 단위로 동일하다. iOS 기본·다크·틴티드 및 watchOS의 원형 마스크를 고려한 구도를 포함한다. 모든 파일은 1024×1024 RGB PNG로 알파 채널이나 미리 잘라낸 모서리가 없다.

앱·Watch·위젯의 빌드 번호를 `agvtool`로 5로 올렸다. 기능·저장 모델·근무 보상·애니메이션·설정 화면은 빌드 4와 동일하다. Android 런처와 앱 안의 마스코트·81개 아이템 미리보기는 변경하지 않았다.

함께 제공된 생성 스크립트는 프로젝트의 Android용으로 내보낸 SceneKit 메시를 Blender Cycles로 렌더링하는 별도 경로다. 내용을 검토해 저장했으며 이번 배포에서 실행하거나 Blender를 설치하지 않았다. 기존 `GenerateAssets.swift`는 이후 미리보기 생성 시 새 아이콘을 덮어쓰지 않도록 바뀌었다. 미리보기 렌더링 로직과 장면 원본 지문은 그대로이며, 제공된 매니페스트의 새 생성기 지문을 대조했다.

## 검증

- 제공 파일의 PNG 서명·1024px 크기·불투명 RGB 및 네 아이콘의 시각적 구도를 확인했다.
- `scripts/check_release_assets.py`: 네 아이콘의 규격·appearance 슬롯, 81개 미리보기, 소스 지문, 3개 개인정보 매니페스트 검사를 통과했다.
- Release Archive와 App Store 배포 IPA 내보내기를 통과했다. 세 타깃의 1.0 (5), 배포 서명·프로파일·App Group 보존·디버그 권한 비활성화를 `verify_distribution_ipa.py`로 확인했다.
- 컴파일된 Assets.car에서 iPhone·iPad의 기본/다크/틴티드와 Watch 아이콘을 확인했다.
- 로컬 빌드는 `nice -n 15`, 단일 작업, Swift `-j1`로 실행했고 시뮬레이터는 켜지 않았다. 확인 시 macOS 열·성능 경고가 없었다. 실제 온도 측정은 아니다.
- [PR CI](https://github.com/eric91405/piyak-bank-ios/actions/runs/36373859162): 리소스·개인정보, Swift 회귀 테스트, 초기 SwiftData 스키마 이전과 프로세스 재시작, iOS·watchOS·위젯 Release 빌드를 모두 통과했다.
- 2026-09-28 12:32 KST에 Xcode의 `Upload succeeded`와 `EXPORT SUCCEEDED`를 확인했다. 이후 Apple에서 제출 준비 완료를 확인하고 기존 내부 출시 검증 그룹(계정 소유자 1명)에 연결했다.

## 심사 자료

기존 85초 실물 영상은 iPhone 16 / iOS 27 / **1.0 (4)**로 촬영됐다. 빌드 5 영상으로 표기하지 않는다. 새 빌드는 앱 아이콘과 빌드 번호만 달라 기존 영상의 기능 흐름은 같다는 점을 심사 노트에 명시한다. 기존 제출 상태는 작업 시작 시 심사 대기 중으로 확인했다. 새 빌드 준비 후 기존 제출을 교체하며 심사 대기는 다시 시작된다.

배포 파일·로그·원본 ZIP·영상은 공개 저장소 밖의 `output/`에 보관한다. 검증 범위는 아이콘 및 배포 패키지 변경에 한하며 새 빌드의 전체 실기기 회귀 테스트를 수행했다고 주장하지 않는다.
