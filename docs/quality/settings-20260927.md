# iOS 1.0 (4) 설정 메뉴 정리 · 2026-09-27

## 변경

설정 첫 화면을 근무 설정·꾸미기 보상·내 데이터·이용 안내·문의하기·개인정보 처리방침의 6개 메뉴로 정리했다. 기존의 긴 설명, 알림 조작, 내보내기와 초기화는 해당 상세 화면으로 이동했다. 이메일·운영자·버전은 ‘문의하기’ 안에서 확인한다. 개인정보처리방침 안의 문의 주소도 유지한다.

- 근무 설정: 기존 시급 편집, 근무 중 변경 제한, 알림 권한 확인과 간격 설정 유지.
- 내 데이터: 기존 CSV 생성·오류 처리와 초기화 확인창 유지. 초기화의 범위와 CSV 가져오기 미지원 안내를 구분해 표시.
- 문의하기: 메일 열기, 주소 복사, 공개 지원 페이지, 운영자와 빌드 번호. 메일 처리 앱이 없으면 주소 복사로 문의하는 방법을 안내.
- 개인정보처리방침: 설정에서 한 번 눌러 앱 내 본문을 읽을 수 있고, 공개 웹 방침 링크도 제공. 초기화 경로를 앱·웹 문서에서 함께 갱신.
- 모델, 보상, 저장소 및 움직임 개선 코드는 변경하지 않았다. 앱·Watch·위젯의 빌드는 `agvtool`로 함께 4로 올렸다. Android 설정 화면은 이번 변경 대상이 아니다.

## Apple 지침 확인

2026-09-27 [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)의 1.5는 앱과 지원 URL에서 쉽게 연락할 방법을, 5.1.1(i)는 앱 및 App Store Connect에서 쉽게 접근 가능한 개인정보처리방침 링크를 요구한다. 문의·방침 메뉴를 첫 화면에 명확히 표시하고 실제 연락처와 공개 URL을 유지하는 방식으로 적용했다. 이메일을 설정 첫 화면에 항상 표시해야 한다는 요구로 해석하지 않는다. 정책 준수 검토는 최종 심사 승인 보장이 아니다.
