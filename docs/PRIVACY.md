# 삐약뱅크 개인정보 처리방침

## 개인정보 처리방침

시행일: 2026년 9월 17일 · 운영자: 김민서

삐약뱅크는 회원가입 없이 사용하는 근무 기록·가상 포인트 꾸미기 앱입니다. 앱에 광고, 추적 SDK, 분석 SDK, 개발자 서버가 없으며, 개발자는 앱 안의 근무 기록을 수집하지 않습니다.

## 기기에 저장하는 정보

입력한 시급, 근무 시작·종료·휴식 시각, 예상 수익, 포인트 거래 내역, 보유 아이템과 설정을 기기에 저장합니다. 시간 보상을 계산하고 중복 적립을 막기 위해 보상 대상 시간 구간, 경과 시간 확인값, 확정 보상 내역도 기기에 저장합니다. 보상 계산에 시급을 사용하지 않으며 이 정보는 개발자 서버로 전송하지 않습니다.

iPhone과 위젯은 App Group 저장소를 사용합니다. 연결된 Apple Watch에는 근무 상태, 시급과 꾸미기 상태를 전달하며 마지막 상태를 워치에 보관합니다.

## 선택 기능과 공유

알림은 사용자가 켰을 때만 권한을 요청합니다. CSV 내보내기는 사용자가 선택한 저장 위치나 앱으로 전달되며, 그 이후 데이터 관리는 해당 서비스의 정책을 따릅니다. 앱 데이터는 사용자의 Apple 기기 백업 설정에 따라 백업에 포함될 수 있습니다. 기기간 클라우드 동기화와 CSV 가져오기 기능은 제공하지 않습니다.

## 보관과 삭제

개별 근무 기록을 수정하거나 삭제해도 중복 적립 방지와 확정 보상 유지를 위한 보상 시간 구간·보상 내역은 기기에 남습니다. 이전 보상 정책의 거래도 별도 원장으로 보관합니다. 설정의 ‘모든 기록 초기화’는 이 보상 내역과 이전 원장을 포함해 근무 기록, 포인트와 아이템을 삭제합니다.

연결된 워치에는 초기화된 상태를 다음 동기화 때 전달합니다. 즉시 워치의 로컬 캐시까지 지우려면 워치 앱도 삭제해 주세요. iPhone 앱을 삭제하면 앱의 로컬 데이터가 제거되지만, 사용자가 내보낸 파일이나 기존 기기 백업은 별도로 삭제해야 합니다.

## 지원 문의

이메일로 문의하면 이메일 주소와 사용자가 보낸 내용을 문의 처리 목적으로 확인합니다. 시급이나 근무 기록 등 민감하게 여기는 내용을 첨부하지 않아도 됩니다. 문의는 처리 완료 후 1년 이내 삭제하며 법령상 보관이 필요한 경우 해당 기간을 따릅니다. 정보 열람·삭제 문의도 아래 주소로 요청할 수 있습니다.
