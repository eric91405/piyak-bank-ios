## 행동·모델·대화 개선 검증

- `ValidateScene.swift`: 단품 81개 + 장착 장면 81개 + 전체 착용 조합 9개, 총 171개 장면을 검사했습니다. 좌표·메시·모서리 반경·카메라 범위·실제 썸네일 검사에서 오류 0개, 검토 경고 0개입니다. [조합 렌더링](quality/room-combinations.jpg)을 직접 확인했습니다.
- `ProbeRoomBehavior.swift`: 실제 SceneKit 행동 시계를 전진시켜 물주기·피아노·강아지·소파·독서를 확인했습니다. 착석 중 근무 상태 변경 시 안전한 하차, 이동 범위, 일시정지/종료를 검사했고 오류 0개입니다. [실제 행동 프레임](quality/room-activities.jpg)은 합성 목업이 아닌 엔진 렌더링입니다.
- 새로운 테스트 27개는 장착품에 맞는 행동 선택·안전한 경로, 대화 질문 분류·기간 범위·Markdown, 취소된 응답 차단·재시도 문맥 보존·AI 비가용, 한국어·영어로 직접 밝힌 정보 회상, 의미 없는 문장부호 입력 차단, 정적 기록 답변의 문맥 제외, 중복·장문 반복의 복구 한도를 검증합니다.
- `ProbeLocalChat.swift`로 **Mac의 실제 Apple Intelligence 모델**을 호출했습니다. 최종 세션 구현의 한국어 3턴에서 이름 ‘민서’와 취향 ‘산책’을 정확히 조회해 표시한 뒤 모델이 산책을 제안했고, ‘다른 조용한 실내 활동’을 요청하자 독서를 제안했습니다. 완료 시간은 약 2.00초 / 0.63초 / 0.84초였습니다. 합성 질문과 메모리 DB만 사용했습니다. 표현 반복성은 남아 있으며 이 짧은 시험이 일반 대화 품질을 보장하지는 않습니다.
- 초기 자유 생성에서 허구의 취향 회상, 직전 답변 복사와 문장 반복을 관찰했습니다. 이름·취향은 명시적인 사용자 정보 조회로 분리하고, 기록·도움말을 모델 문맥에서 제외했으며, 프레임워크가 실제 대화 세션을 유지하도록 수정했습니다. 중복·폭주는 한 번 복구하고 계속 실패하면 오류를 표시합니다. 일반 대화·추천은 여전히 생성 모델의 오류 가능성이 있습니다. **최종 대화 엔진은 Mac에서 확인했으며 실물 iPhone의 품질·속도·발열 검증을 대신하지 않습니다.**
- 생성 미리보기에는 원본 모델·생성기 파일의 SHA-256 지문을 기록하고 CI에서 대조합니다. 모델을 바꾸면 이미지도 다시 생성해야 검사에 통과합니다.

[실제 화면 캡처](screenshots/): iPhone 1320×2868, iPad 2064×2752. 원본 시뮬레이터 화면을 크기 변경 없이 JPEG로 내보냈으며 합성 목업이 아닙니다. 접근성 다크 모드 이미지는 QA 참고용입니다.

빌드·렌더·AI 추론·시뮬레이터를 동시에 실행하지 않았고, 화면 확인은 한 기기씩 수행했습니다. 추가 발열 요청 이후 로컬 검증은 낮은 프로세스 우선순위·작업 수 1개와 냉각 간격을 적용하고, 시뮬레이터를 모두 종료했습니다. 마지막 앱 전체 빌드는 원격 GitHub Actions에서 수행합니다. 대화 검증 도구도 심한 발열 상태에서는 중단하도록 구성했습니다. M4·16GB Mac에서 10초 간격으로 CPU·메모리 압력·스왑·macOS 발열 단계를 관찰한 마지막 테스트 구간의 전체 CPU 평균은 약 11~14%, 메모리 압력은 정상, 발열 단계는 `nominal`이었습니다. 이는 표면 온도나 내부 센서 온도 측정값은 아닙니다.
