# 삐약뱅크 Android 개인정보 처리방침

시행일: 2026년 9월 21일 · 운영자: 김민서

삐약뱅크는 회원가입 없이 근무 시간을 기록하고 가상 포인트로 방을 꾸미는 앱입니다. 앱에 광고·분석·추적 SDK와 개발자 서버는 없으며 개발자가 앱의 근무 기록을 수집하지 않습니다. Android 휴대폰·태블릿 앱과 동반 Wear OS 앱에 적용되는 안내입니다.

## 기기에 저장하는 정보

입력한 시급, 근무·휴식 시각, 예상 수익, 포인트 거래 내역, 보유·장착 아이템, 설정을 앱 전용 저장소에 보관합니다. 시간 보상과 중복 정산 방지를 위해 측정 시간 구간, 기기 부팅 횟수·경과 시간 기준값, 확정 보상 내역, 처리한 워치 명령 식별자를 저장합니다. 보상 계산에는 시급을 사용하지 않습니다.

홈 화면 위젯은 같은 기기에 저장한 기록에서 계산한 예상 수익·근무 상태·포인트와 갱신 시각을 표시합니다.

## Wear OS 동기화

워치를 연결해 사용하면 근무 상태와 제어 명령, 오늘의 예상 수익, 기본 시급, 잔액·레벨, 장착 아이템 식별자를 연결된 Android 휴대폰과 Wear OS 워치 사이에 전달합니다. 전체 근무 기록 원문은 워치에 전송하지 않습니다. 워치 화면에는 마지막으로 받은 상태가 앱 실행 중 표시되며, 새로 연결할 때 최신 상태를 요청합니다.

통신은 Google Play services의 Wearable Data Layer를 사용합니다. Bluetooth 연결을 이용할 수 있고, 연결 환경에 따라 **Google 서버를 통한 종단간 암호화 중계**를 사용할 수 있습니다. 개발자 서버로 보내거나 개발자가 열람하는 방식은 아닙니다. 자세한 통신 방식은 [Google의 Data Layer 설명](https://developer.android.com/training/wearables/data/overview)을 참고하세요. Wear OS 기능은 Android 휴대폰과의 연결이 필요하며 iPhone 앱과 동기화하지 않습니다.

## 선택 기능과 공유

알림은 사용자가 켰을 때만 권한을 요청하며 거부해도 근무 기록과 꾸미기 기능을 사용할 수 있습니다. 정확한 알람·위치·연락처·카메라·마이크·사진 접근 권한은 요청하지 않습니다.

CSV 내보내기를 선택하면 사용자가 지정한 문서 제공자나 저장 위치에 파일을 씁니다. 이후 파일 관리는 선택한 서비스의 정책을 따릅니다. CSV는 보관·열람용이며 가져오기 기능은 제공하지 않습니다. 앱은 Android 자동 클라우드 백업과 앱 데이터의 기기 간 자동 전송에서 자체 저장소를 제외하도록 설정합니다. 별도의 클라우드 동기화나 iOS 데이터 자동 이전은 지원하지 않습니다.

## 보관과 삭제

개별 근무 기록을 수정·삭제해도 확정 보상과 중복 적립 방지를 위한 보상 내역은 남습니다. 설정의 전체 초기화는 근무 기록·포인트·보상 내역·보유 아이템·사용자 설정을 초기화하고 기본 제공 아이템으로 돌아갑니다. 초기화된 상태는 다음 연결 때 워치에 전달됩니다. 앱을 삭제하면 앱 전용 데이터도 삭제됩니다. 내보낸 CSV는 별도로 삭제해야 합니다.
