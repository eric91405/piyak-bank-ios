# 삐약뱅크 (PiyakBank)

**일하는 나에게, 작은 친구 하나.**

시급과 근무 시간으로 예상 수익을 기록하고, 타이머로 쌓은 시간 보상으로 병아리의 방을 꾸미는 앱입니다. iOS · Apple Watch와 Android · Wear OS 버전을 출시 준비 중입니다. 첫 버전은 무료이며 광고, 회원가입, 인앱결제가 없습니다.

기록은 기기에 저장하며 개발자 서버로 전송하지 않습니다. 포인트는 앱 꾸미기 전용 가상 포인트로, 현금 가치나 환전·송금·인출 기능이 없습니다. 삐약뱅크는 실제 은행이나 급여 지급 서비스가 아닙니다.
